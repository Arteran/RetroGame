## Особливості

- **Захоплююча 3D Графіка**: Пориньте у прекрасний підводний світ.
- **Плавні Анімації**: Реалістичні взаємодії та візуальні ефекти завдяки GSAP.
- **Висока Продуктивність**: Оптимізовано для високої частоти кадрів за допомогою Vite та React.

### Запуск проєкту

1. Встановіть залежності:
   ```bash
   npm install
   ```

2. Запустіть сервер розробки:
   ```bash
   npm run dev
   ```

Відкрийте `http://localhost:5173` у вашому браузері.
